# 学生考勤平台

经典工作台模式（左侧导航 + 顶栏 + 内容区）的高校学生上课考勤管理系统。**零第三方依赖**：Node.js 原生 HTTP 服务 + JSON 文件存储 + 原生 ES Module 单页前端，开箱即用，无需 `npm install`。

## 快速开始

环境要求：Node.js ≥ 16。

```bash
git clone <your-repo-url>
cd 学生考勤平台
node server/index.js        # 或：npm start，或 bash scripts/start.sh
```

打开 http://localhost:3000 （自定义端口：`PORT=8080 node server/index.js`）。

## 默认账号

| 角色 | 账号 | 初始密码 | 权限 |
|------|--------|--------|------|
| 管理员 | admin | admin123 | 全部模块 + 账号管理 |

> 其余角色账号（权益部 / 纪律委员 / 班主任 / 辅导员）首次启动**不会**自动创建，请登录后通过「账号管理」模块按角色生成。管理员账号在首次启动时由 `store` 自动创建（`data/users.json` 缺失或损坏时重建）。

## 五大功能模块

1. **账号管理**（管理员）：五类角色——管理员、权益部、纪律委员、班主任、辅导员。
   - *学生账号生成*（纪律委员 / 权益部）：选择班级与学生后自动生成——账号 = 学号、姓名自动带出、初始密码 = **Hzpt@学号后六位**；纪律委员自动授权管理本班级。
   - *教职工名单*：独立页签维护教职工（工号、姓名、岗位、所带班级），默认按班级生成班主任与辅导员名单。
   - *教职工账号生成*（班主任 / 辅导员）：从名单中选择工号，姓名与所带班级自动带入，初始密码 = **Hzpt@工号**，只读查看考勤与统计数据。
   - *首登强制改密*：生成的账号首次登录时强制进入修改密码页，完成前其他功能不可用；管理员"重置密码"后同样要求重新改密。
   - 常规能力：编辑 / 停用 / 启用 / 删除、按角色与关键字筛选、角色分配。
2. **班级名单管理**（权益部 / 管理员）：字段为年级、班级、姓名、学号、纪律委员、辅导员、班主任；提供 Excel 模板下载、批量导入（按"班级 + 学号"自动新增或更新、逐行报错）、批量删除、单条增改，支持按年级 / 班级 / 关键字筛选与分页。
3. **考勤点名**（纪律委员）：选择上课日期、节次（1-2 / 3-4 / 5-6 / 7-8 节，可多选）、课程名称与任课老师，加载本班名单后逐个标记出勤 / 迟到 / 缺勤 / 请假（支持"全部出勤 / 全部缺勤"快捷操作）。同一班级同一天相同时段不允许重复点名。
   - **假单自动同步**：发起点名时，已被已通过假单覆盖的学生自动预标记为"请假"并备注事由（切换日期 / 节次按假单重新预填，手动标记保留）。
   - **权限差异化**：纪律委员提交点名后记录锁定为只读，仅可查看；权益部 / 管理员可在详情中单独修改学生考勤状态，保存后系统按假单自动复核。
   - **任课老师签字确认**：提交后生成免登录确认链接，复制发给任课老师（微信等），老师手机打开核对点名摘要并**手写签名确认**，记录留痕确认人与时间；记录被修改后需重新确认。
4. **假单管理**（权益部 / 管理员）：支持**上课时间段设置**与基于时间段的假单判定，全部导入导出统一使用 `.xlsx`（Excel）格式。
   - *上课时间段设置*：权益部可配置 1-2节 / 3-4节 / 5-6节 / 7-8节 的标准上课时间（默认 08:00~09:40、10:00~11:40、14:00~15:40、16:00~17:40），作为请假判定基准；调整后仅影响后续导入与"重新应用"。
   - *批量导入假单*：模板字段为班级、姓名、学号、**请假开始日期、请假结束日期**、请假开始时间、请假结束时间、假别、事由，支持多天请假（首日起始时间生效、末日到结束时间生效、中间日全天）。
   - *导入系统请假数据*：直接上传外部系统导出的《学生请假信息》Excel，字段自动映射——学号 / 班级 / 姓名 原样对应，请假开始时间 → 开始日期 + 开始时间，请假结束时间 → 结束日期 + 结束时间，请假类型 → 假别，请假事由 → 事由；**审核状态严格等于"已通过"才导入**（未通过 / 不通过 / 待审核 / 空值一律跳过并注明原因）。
   - *判定与对账*：当天请假时间段**完整包含**某节次上课时间，该节次请假生效——缺勤自动改为请假并备注；已登记"请假"但未被覆盖则自动改回"缺勤"。导入、重新应用、删除假单均触发对账；点名保存时也即时套用。
   - *去重机制*：导入时按"学生 + 请假时间段（起止日期 + 起止时间）"判重，已存在的记录自动跳过并注明，避免重复导入。
   - *筛选*：支持按班级（多选下拉）与状态组合筛选假单。
   - *校验规则*：仅需校验学号与姓名存在于班级名单且指向同一名学生（班级名称以名单为准，可容忍表述差异）；日期 / 时间格式错误、时间先后颠倒等逐行报错，不影响其他行。
5. **数据统计**（权益部 / 管理员）：三个页签——
   - *班级汇总 / 学生明细*：按日期范围与班级统计点名次数、应到人次、出勤、迟到、缺勤、请假、到课率，一键导出 Excel（.xlsx）。到课率 =（出勤 + 迟到）÷ 应到人次。
   - *缺勤统计*：按**周 / 月 / 年 / 自定义区间**统计每位学生的缺勤节数（缺勤按整节计算，涉及 1-2节 记 2 节；跨天连续请假逐日计入）；支持年级、班级、学号/姓名关键字与**缺勤节数区间**复合筛选，结果按合计倒序排列，动态分桶列展示各周 / 月 / 年的缺勤分布，一键导出 Excel。**点击学生姓名可查看缺勤详情**：逐条列出缺勤日期（含星期）、缺勤节次、各节上课时间段（按时间基准）、课程名称、任课老师与备注，支持按时间升降序排序及课程 / 老师 / 备注关键字筛选。

## 导入模板说明（均为 .xlsx 格式）

- 名单模板：`年级,班级,姓名,学号,纪律委员,辅导员,班主任`（班级、姓名、学号必填，年级选填）
- 假单模板：`班级,姓名,学号,请假开始日期,请假开始时间,请假结束日期,请假结束时间,假别,事由`
  - 日期支持 Excel 日期单元格或 `2026-09-24`、`2026/9/24`、`2026年9月24日`
  - 时间为 24 小时制 `HH:MM`（如 08:00、14:30）
  - 请假开始日期 = 结束日期表示单日请假；多天请假首日起始时间生效、末日到结束时间生效、中间日全天
  - 覆盖判定：当天请假时间段完整包含节次上课时间才生效
  - 假别自动归为公假 / 病假 / 事假 / 其他
- 系统请假数据：直接上传外部系统导出的《学生请假信息》表，无需转换（字段映射见功能说明）

## 角色与数据规则

- 纪律委员只能看到并操作管理员分配给自己的班级；提交点名后记录锁定为只读。
- 权益部 / 管理员可在点名详情中单独修改学生考勤状态；保存后系统按假单自动复核。
- 假单按"上课时间段基准"判定覆盖，连续跨天请假整段视为请假。自动校验在两个节点触发：**提交 / 修改点名时**（对会话内全部学生）与**假单导入 / 重新应用 / 删除时**（对该生请假周期内）——覆盖的"缺勤"改"请假"，未覆盖的"请假"改"缺勤"；发起点名时还会按假单自动预填请假。
- 假单导入仅校验学号与姓名在班级名单中且指向同一名学生（班级名称以名单为准）；系统请假数据仅导入审核状态"已通过"的记录。
- 统计对"同一学生同一天同一节次"取最新一次记录，避免重复计次。

## 常用操作

- 重置数据：停止服务 → 删除 `data/` 目录 → 重新启动（管理员账号会重建）。
- 修改端口：`PORT=8080 node server/index.js`。
- 运行时数据位于 `data/*.json`，可直接备份或迁移；该目录不纳入版本控制。

## 移动端适配

- 采用响应式设计：≤920px 侧边栏收起为抽屉导航（顶栏汉堡按钮唤出，点遮罩或菜单自动关闭）；≤640px 表格自动转为卡片式布局（字段名随行显示）、统计卡片两列、操作按钮加宽。
- 触摸优化：按钮与状态选择器加大触摸面积，输入框移动端使用 16px 字号避免 iOS 聚焦缩放，禁用点击高亮闪烁。
- 加载性能：静态资源启用 gzip 压缩与 ETag 协商缓存，全程零外部依赖，弱网下也可快速加载。
