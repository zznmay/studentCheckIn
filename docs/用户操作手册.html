学生考勤工作台 · 用户操作手册

面向纪律委员、权益部、学院考勤负责人的日常操作指南。本手册以「图文结合 + 分步说明」的方式，帮助非技术人员独立完成考勤管理、纪律维护与权益处理等各项工作。

版本：应用 2.1 线上地址：student-attendance-21705.app.workbuddy.host 编制：2026-09-28 阅读对象：三大一线角色

i关于本手册

本手册配套的线上系统为「学生考勤工作台 2.1」，支持电脑浏览器与手机微信/浏览器访问。系统按角色授权，不同角色登录后看到的菜单与可操作范围不同。

  • 纪律委员：负责本班课堂点名、记录出勤，并把确认链接发给任课老师。
  • 权益部：负责请假（假单）的导入与核对、班级名单维护、考勤状态更正、数据导出统计。
  • 学院考勤负责人：负责开通一线账号、分配点名权限，并以学院视角统筹名单、考勤、假单与统计。
!
所有操作均为在线实时生效，数据保存在学院服务器（云端）。建议首次登录后立即修改初始密码，并定期通过「数据管理」做好备份。

1一、快速上手

1.1 登录与修改密码

  1. 打开系统：在电脑或手机浏览器输入线上地址 student-attendance-21705.app.workbuddy.host，进入登录页。手机可把链接发给同事，或在微信中直接点开。
  2. 输入账号与密码：账号由学院考勤负责人开通并下发；初始密码规则见下表。登录页右侧小眼睛可切换密码明文/密文，方便核对。
  3. 首次登录强制改密：首次登录后系统会自动跳到「修改密码」页，请输入新密码并保存。初始密码一旦用于他人账号，请务必第一时间修改，避免账号被盗用。
  4. 登录成功：自动进入「工作台」，左侧/顶部菜单即为你当前角色可使用的功能。

3.2 发起一次课堂点名（核心操作）

  1. 进入发起点名：侧边栏点击「考勤点名」→ 右上角蓝色按钮 ＋ 发起点名。
  2. 选择点名信息： ① 班级（下拉选择你被授权的班级）；② 上课日期（默认今天，可改）；③ 节次（勾选 1-2节 / 3-4节 / 5-6节 / 7-8节，可多选）；④ 课程名称（必填，如"高等数学"）；⑤ 任课老师（选填）。
  3. 系统自动加载名单：选好班级后会自动列出全班同学，并预填考勤状态： 已被通过假单覆盖的同学 → 自动预标为「请假」并备注事由；其余同学 → 默认「出勤」。你只需对实际不符的同学手动改一下即可。
  4. 标记考勤状态：在每个同学行右侧，点击 出勤迟到缺勤请假 四个按钮之一。需要快速操作可用顶部「全部出勤 / 全部缺勤」。
  5. 填写备注（可选）：如某同学迟到或请假，可在备注列填写原因（如"迟到 10 分钟""病假"）。
  6. 保存点名记录：点击右下角 保存点名记录。若当天该班级同一节次已点过名，系统会提示"记录已存在"并跳转查看，不会重复创建。

3.3 查看、核对与确认

① 复制确认链接发给任课老师

保存点名后进入「点名详情」页，点击 复制确认链接（发给任课老师）。把这条链接通过微信等方式发给本节课任课老师，老师打开后会核对名单并手写签名确认（老师无需登录）。

i
确认机制说明：任课老师签字确认后，该记录即被锁定为「已确认」。老师只需签字一次，后续考勤状态的修改不影响这次确认的有效性。详情页会显示「已确认 · 确认人 · 时间」以及老师的手写签名图片。

② 点名详情为「只读锁定」

纪律委员提交点名后，记录会锁定为只读（页面显示「已锁定 · 仅查看」）。这是因为考勤录入的第一责任人就是你，提交即生效；若之后需要更正某位同学的状态（例如发现记错），请通知权益部或学院考勤负责人在详情页修改。

4四、权益部操作手册

你是请假（假单）与考勤质量的把关人。核心职责：把学生请假信息导入系统、让假单自动对账考勤、维护班级名单、对异常考勤进行更正，并导出统计报表。

4.1 假单管理（核心职责）

侧边栏点击「假单管理」进入。页面顶部一排按钮即你的主要操作入口。

① 批量导入假单（最常用）

  1. 点击右上角 批量导入假单 → 在弹窗中先下载导入模板（如未下载过）。
  2. 在 Excel 模板中按列填写：班级、姓名、学号、请假开始日期、开始时间、结束日期、结束时间、假别、事由。跨天请假只需填一条：系统按"连续时间段"处理（首日自开始时间、中间日全天、末日至结束时间）。单日请假两个日期填同一天。
  3. 保存 Excel（.xlsx 格式），回到弹窗上传，系统逐行校验：学号与姓名需存在于班级名单；日期/时间格式错误或先后颠倒会逐行报错，方便你定位修正。
  4. 确认无误后提交，系统按当天上课时间段基准自动完成考勤双向对账（见下方规则），导入完成。

② 导入系统请假数据（对接外部系统）

如果你校有独立的请假审批系统，导出了《学生请假信息》Excel，可点击 导入系统请假数据 上传。系统会只导入"审核状态=已通过"的记录，未通过/待审核自动跳过，导入后同样自动对账考勤。

③ 上课时间段设置（决定假单是否生效）

点击 上课时间段设置 可调整每节课的起止时间（默认 1-2节 08:00–09:40、3-4节 10:00–11:40、5-6节 14:00–15:40、7-8节 16:00–17:40）。判定规则：请假时间段需完整包含某节次的上课时间，该节次的请假才会生效。调整基准仅影响后续假单与"重新应用"，不会自动改动已有考勤。

④ 查看、筛选与处理

  • 筛选：可按班级（多选）、状态（待生效/已生效）、关键词（姓名/学号/班级/事由）查询。
  • 状态三态（系统用颜色区分）：
    待生效 请假还没开始 生效中 请假期间内，点名缺勤会自动改判请假 已生效 已成功套用对账 未生效 请假已结束但期间无缺勤可套用
  • 重新应用：对"待生效/未生效"的假单，若想立即套用对账，点「重新应用」即可把对应缺勤改为请假（或把无覆盖的请假改回缺勤）。
  • 删除：错误假单点「删除」。删除后会自动重新对账——原本因这张假单被改成的"请假"会改回"缺勤"。

4.2 班级名单管理

侧边栏点击「班级名单」进入（菜单名"班级名单管理"）。你可以：

  • 查看与搜索：按年级、班级、关键词（姓名/学号/辅导员等）筛选；支持勾选批量删除。
  • 批量导入：点 批量导入 下载模板，填写后上传，覆盖/更新全班名单（含年级、班级、姓名、学号、辅导员、班主任、纪律委员等字段）。
  • 新增学生：点 ＋ 新增学生 单条录入。
  • 单条修改：每行「操作」可编辑或删除。
i
名单是点名与假单匹配的基础。若某同学请假导入时提示"名单外"，请先确认其班级、学号、姓名是否与名单完全一致（系统对全角/半角、空格较敏感）。名单维护建议由权益部统一负责，避免多处不一致。

4.3 考勤更正与数据统计

① 考勤点名中的更正

在「考勤点名」列表进入任意记录的「点名详情」，你（权益部）拥有修改权限：可单独改某位同学的状态并「保存修改」。保存后系统会按假单再次自动复核（未覆盖的"请假"会被改判"缺勤"）。这对纠正纪律委员误记、补登请假非常有用。

!
权限边界：纪律委员提交的记录对纪律委员本人是只读锁定的；只有权益部、学院考勤负责人、管理员可以更正。请勿在未经核对的情况下随意改动他人录入的考勤。

② 数据统计与导出

侧边栏点击「数据统计」，有三个标签页：

  • 班级汇总：各班点名次数、应到人次、出勤/迟到/缺勤/请假人次、到课率。
  • 学生明细：到每个学生级别的到课率，便于精准跟踪长期缺勤同学。
  • 缺勤统计：按周/自定义时间段统计各班缺勤情况，可设缺勤次数阈值筛选重点对象。

点击右上角 导出当前数据（Excel） 即可把当前查询结果导出为 Excel 报表，用于学院通报或存档。

✓
到课率计算公式：到课率 =（出勤 + 迟到）÷ 应到人次。缺勤节数按整节计算（一条涉及"1-2节"的缺勤记 2 节）。

5五、学院考勤负责人操作手册

你是学院考勤工作的统筹者。除了一线业务（名单、点名、假单、统计）的院级视角外，你还负责开通账号、分配点名权限——这是保障纪律委员、权益部能正常工作的前提。

5.1 账号管理（你的专属权限）

侧边栏点击「账号管理」（仅管理员与你能看到）。页面有两个标签页：系统账号 与 教职工名单。

① 新建账号（开通纪律委员 / 权益部等）

  1. 在「系统账号」页点右上角 新建账号。
  2. 选择账号角色：纪律委员（学生）/ 权益部（学生）/ 班主任（教职工）/ 辅导员（教职工）等。管理员与"学院考勤负责老师"属于特权角色，仅超级管理员可创建，你（负责人）的界面中不会显示这两个选项，以防越权。
  3. 学生账号（纪律委员/权益部）：选定角色后，系统从班级名单自动带出对应学生姓名，账号=学号，初始密码=Hzpt@学号后六位。
  4. 对纪律委员：勾选「可点名班级」——这是关键一步！只有在这里勾选了他负责的班级，该纪律委员登录后才能对相应班级发起点名，否则会提示"暂无可点名的班级"。
  5. 点「生成账号」，账号立即生效，对方即可用学号+初始密码登录（首次登录强制改密）。

② 编辑账号（调整角色 / 班级 / 姓名）

在账号列表每行点「编辑」，可修改：姓名、角色（可多选，支持多重身份）、可点名班级。例如某同学既是纪律委员又是权益部，可同时勾选两个角色，权限自动合并。

③ 重置密码 / 停用 / 删除

  • 重置密码：同学忘记密码时，点「重置密码」恢复为初始密码（学生=Hzpt@学号后六位），再让其首次登录改密。
  • 停用 / 启用：毕业或离任可「停用」账号（停用后无法登录），需要时再启用，比删除更稳妥。
  • 删除：彻底移除账号（不可恢复，请谨慎）。你无法删除管理员或另一位学院考勤负责人的账号。

④ 教职工名单

切到「教职工名单」标签页，维护班主任、辅导员的工号、姓名、岗位、所带班级。生成班主任/辅导员账号时会从这里选择并自动带入信息。

5.2 院级业务操作（名单 / 点名 / 假单 / 统计）

学院考勤负责人对「班级名单、考勤点名、假单管理、数据统计」拥有全院范围的权限（不限班级），操作方式与权益部一致，区别仅在于你能看到并处理所有班级的数据：

  • 班级名单：查看/导入/维护全院各班级学生。
  • 考勤点名：可对任一班级发起点名，也可进入任意记录更正考勤状态。
  • 假单管理：导入/核对全院假单，重新应用或删除。
  • 数据统计：查看全院到课率与缺勤统计并导出报表。
i
与权益部的区别：权益部能做的你都能做，且不受班级限制；你独有的权限是「账号管理」（开通/分配一线账号）。数据备份（数据管理）仅管理员可用，如需定期备份请协调管理员。

6六、关键业务规则（务必了解）

6.1 假单如何"生效"对账考勤

系统判定逻辑（权益部/负责人调整过上课时间段基准后同样适用）：

  • 当一条假单的请假时间段完整包含某节课的上课时间，该节课的考勤为「缺勤」时 → 系统自动改为「请假」并备注假别与事由。
  • 若某条已登记「请假」但未被任何假单覆盖（例如手误标记或假单被删）→ 系统自动改回「缺勤」。
  • 因此：导入假单后无需手工逐条改考勤，系统会对账；发现遗漏可点「重新应用」立即套用。

6.2 点名记录的"锁定"与"更正"

  • 纪律委员提交后记录对其本人为只读锁定，保证录入责任清晰。
  • 权益部 / 学院考勤负责人 / 管理员可在详情页修改任意学生的考勤状态并保存，保存后系统再次按假单复核。

6.3 任课老师确认"一次永久有效"

任课老师通过确认链接签字后，记录即标记为「已确认」，并显示确认人、时间与手写签名。老师只需签字一次；此后考勤状态被更正，该次确认依然有效（更正不会抹掉老师的原始确认）。

7七、常见问题 FAQ

纪律委员：点「发起点名」后提示"暂无可点名的班级"？
你的账号还没被分配班级权限。请联系学院考勤负责人在「账号管理 → 编辑你的账号 → 勾选可点名班级」后重试。
权益部：假单导入后，某个同学仍显示"缺勤"没变成"请假"？
可能原因：① 该生当天该节次本就没有点名记录（假单无考勤可套用，显示"未生效"）；② 假单时间段未完整覆盖该节课上课时间（检查"上课时间段设置"）；③ 学号/姓名与名单不一致导致未匹配。可点该假单「重新应用」或核对名单与时间段。
权益部：导入假单提示"名单外跳过"很多条？
说明这些学生的学号/姓名在班级名单中找不到。请先确认「班级名单」已正确导入，且 Excel 中的学号、姓名、班级与名单完全一致（注意全角/半角、多余空格）。修正后重新导入即可。
学院考勤负责人：我能创建管理员账号吗？
不能。管理员与"学院考勤负责老师"属于特权角色，仅超级管理员可创建/编辑/删除，你的界面中不会出现这两个角色的创建选项，这是系统的防越权设计。
同学忘了密码怎么办？
学院考勤负责人或管理员在「账号管理」中对该账号点「重置密码」，恢复为初始密码（学生=Hzpt@学号后六位），同学再次登录时会被要求强制修改。
记录提交后发现记错了，能改吗？
纪律委员提交后记录对其本人只读。请通知权益部或学院考勤负责人进入「点名详情」修改对应学生状态并保存，系统会自动重新复核假单。
数据会丢吗？如何备份？
数据保存在学院云端服务器，日常操作不会丢失。但为防极端情况，管理员可通过「数据管理」手动备份，或开启"定时自动备份"。建议重要节点（如月末）由管理员导出一份备份留存。
手机能用吗？
可以。系统适配手机浏览器与微信内置浏览器，菜单在手机上以上下抽屉形式呈现，操作逻辑与电脑一致。
